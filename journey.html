How I'm getting there.

01 / THE BEGINNING

I became interested in understanding how websites and software are actually created. That curiosity pushed me toward programming and web development.

02 / HTML

Learning the structure.

HTML became the first real foundation — learning how headings, sections, links, images, forms and other elements come together to create a webpage.

03 / CSS

Making the web look alive.

CSS opened up an entirely different side of development — layouts, responsive design, typography, spacing, animations and visual identity.

04 / JAVASCRIPT

Adding logic.

JavaScript is the next major step — learning variables, functions, loops, logic and how code can make a website interactive.
